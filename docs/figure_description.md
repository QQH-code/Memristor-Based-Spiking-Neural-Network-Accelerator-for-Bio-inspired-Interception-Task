# Figure Descriptions

The figures in `figures/paper_figures/` are the final manually curated public figure set associated with the project. They were copied from the manually selected public figure folder and renamed for GitHub display.

See `audit/figure_inventory.csv` for the complete figure inventory.

## Included Figures

### `fig01_task_overview.png`

Bio-inspired interception task overview showing geometric variables used in the task formulation.

### `fig02_accelerator_architecture.png`

Memristor-based SNN accelerator architecture, including input layer, memristor crossbar synapses, hidden/output neurons, and synaptic interface circuitry.

### `fig03_system_level_result_1.png`

Representative system-level interception trajectory results.

### `fig04_system_level_result_2.png`

Additional system-level trajectory results showing multi-case or variation behavior.

### `fig05_neuron_layout.png`

Physical layout associated with the neuron circuit used in the VLSI implementation.
