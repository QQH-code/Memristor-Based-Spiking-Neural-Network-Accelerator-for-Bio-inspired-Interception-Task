# Figure Descriptions

The figures in `figures/paper_figures/` are the final manually curated public figure set associated with the project. They were copied from the manually selected public figure folder and renamed for GitHub display.

See `audit/figure_inventory.csv` for the complete figure inventory.

## Included Figures

### `fig01_task_overview.png`

Short title: Bio-inspired interception task overview

Description: Illustrates the bio-inspired interception task and the relationship between predator/prey positions and prediction variables.

### `fig02_accelerator_architecture.png`

Short title: Memristor-based SNN accelerator architecture

Description: Shows the overall memristor crossbar synapse structure, input layer, hidden layer, output neuron, and synaptic interface circuit used in the accelerator workflow.

### `fig03_system_level_result_1.png`

Short title: System-level interception trajectory results

Description: Shows representative predator-prey trajectory results generated by the system-level evaluation.

### `fig04_system_level_result_2.png`

Short title: System-level trajectory variation results

Description: Shows additional system-level trajectory results, including variation or multi-case behavior.

### `fig05_neuron_layout.png`

Short title: Neuron layout

Description: Shows the physical layout associated with the neuron circuit used in the VLSI implementation.
