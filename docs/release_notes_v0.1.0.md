# v0.1.0 - Initial Public Research-Code Release

This draft release note summarizes the initial public repository preparation.

## Included

- Curated MATLAB workflow scripts for SNN, crossbar, neuron, mapping, waveform-processing, and analysis tasks.
- Verilog-A model files used by the research workflow.
- Sanitized Spectre workflow templates with placeholders instead of private paths.
- Manually curated public figures associated with the project.
- MIT License.
- Citation metadata for the two related arXiv papers:
  - arXiv:2605.31141
  - arXiv:2605.31299

## External Requirements

Full circuit-level simulation requires an external licensed Cadence/Spectre environment and a compatible 130 nm PDK/ODK. These resources are not included in the repository.

## Notes

This release is intended as a public research-code and workflow-documentation package. It is not a complete turnkey reproduction package.
