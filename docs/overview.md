# Project Overview

This repository is a curated public research-code release for the memristor-based spiking neural-network accelerator for bio-inspired interception tasks.

It contains:

- MATLAB scripts from the SNN, crossbar, neuron, mapping, waveform-processing, and result-analysis workflow.
- Verilog-A model files used by the research flow.
- Sanitized Spectre workflow templates.
- Manually curated public figure images associated with the project.
- Documentation and audit records explaining what is included and what was excluded.

The repository is not a complete local reproduction package. Full circuit-level simulation requires an external licensed Cadence/Spectre environment and a properly configured 130 nm PDK/ODK, which are not included.
