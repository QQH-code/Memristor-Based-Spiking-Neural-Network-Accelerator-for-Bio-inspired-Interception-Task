# Figures

This directory contains the final manually curated public figure set for the repository.

The full PowerPoint deck is not included. The public figures were selected manually from `github_selected_figs` and renamed for GitHub display.

Included files:

- `paper_figures/fig01_task_overview.png`
- `paper_figures/fig02_accelerator_architecture.png`
- `paper_figures/fig03_system_level_result_1.png`
- `paper_figures/fig04_system_level_result_2.png`
- `paper_figures/fig05_neuron_layout.png`

The figure inventory is documented in `audit/figure_inventory.csv`, and sanitized figure descriptions are provided in `docs/figure_description.md`.
