# Figures

This directory contains the final manually curated public figure set for the repository.

## Included Figures

- `paper_figures/fig01_task_overview.png`: Bio-inspired interception task overview showing geometric variables used in the task formulation.
- `paper_figures/fig02_accelerator_architecture.png`: Memristor-based SNN accelerator architecture, including input layer, memristor crossbar synapses, hidden/output neurons, and synaptic interface circuitry.
- `paper_figures/fig03_system_level_result_1.png`: Representative system-level interception trajectory results.
- `paper_figures/fig04_system_level_result_2.png`: Additional system-level trajectory results showing multi-case or variation behavior.
- `paper_figures/fig05_neuron_layout.png`: Physical layout associated with the neuron circuit used in the VLSI implementation.

The figure inventory is documented in `audit/figure_inventory.csv`.
