# Spectre Templates

These files are workflow templates only.

They require:

- a licensed Cadence/Spectre installation,
- a local 130 nm PDK/ODK setup,
- local model library files,
- environment variables such as `$SPECTRE_BIN`, `$PDK_ROOT`, `$SPECTRE_MODEL_DIR`, and `$CADENCE_HOME`.

The repository does not include proprietary PDK/ODK files, Cadence environment files, license files, simulator binaries, raw simulator outputs, or server-specific paths.

Use these templates to understand and adapt the workflow in your own authorized environment.
